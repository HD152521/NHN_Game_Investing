# PRD — 오늘의 던전 (가제: TODAY'S DUNGEON)

> NAN 2026 · NHN Game × AI Hackathon 사전 과제
> 문서 버전 v1.0 / 작성일 2026-07-29

---

## 1. 한 줄 소개

**당신의 오늘 하루가 3분짜리 던전이 된다.**
일기 세 줄을 쓰면, 오늘 당신을 괴롭힌 것들이 몬스터가 되어 몰려온다.

---

## 2. 제품 정의

### 2.1 무엇인가

3분 세션의 **탑다운 서바이버라이크 아케이드 게임**이다.
게임 자체로 완결되어 있으며, 일기는 **콘텐츠를 개인화하는 얇은 레이어**로만 작동한다.

### 2.2 무엇이 아닌가 (Non-Goals)

| 아닌 것 | 이유 |
|---|---|
| 일기 앱 | 일기는 입력 수단이지 제품의 본체가 아니다 |
| AI가 게임을 생성하는 도구 | 게임 로직·밸런스는 100% 사람이 고정한다 |
| 감정 케어 / 힐링 서비스 | 재미가 1순위, 공감은 부산물 |
| 소셜 / 멀티플레이 | 사전 과제 범위 밖 |

### 2.3 설계 원칙 (가장 중요)

> **1. 일기 없이도 재미있어야 한다.**
> 일기를 쓰지 않고 "그냥 시작"을 눌러도 완전한 게임이 돌아간다.
> 심사자가 개인정보를 입력하기 싫어할 가능성을 100% 방어한다.
>
> **2. AI는 수치를 정하지 않는다.**
> AI가 채우는 것은 **이름 · 색 · 문구 · 배치 순서**뿐이다.
> HP, 공격력, 스폰율은 전부 고정 테이블에서만 나온다. 밸런스는 절대 흔들리지 않는다.
>
> **3. 개인화는 "많이"가 아니라 "정확히" 한 방.**
> 오늘의 보스 이름 하나가 나머지 전부보다 강력하다.

## 3. 장르 선택 근거

오토러너(Life is a Game 방식)가 아니라 **서바이버라이크**를 택한 이유:

| 기준 | 오토러너 | 서바이버라이크 | 판정 |
|---|---|---|---|
| 조작 학습 시간 | 즉시 | 즉시 (이동만) | 동일 |
| 게임 자체의 재미 상한 | 낮음 (분기 감상용) | 높음 (성장 루프) | **서바이버** |
| 재플레이 동기 | 약함 | 강함 (빌드 조합) | **서바이버** |
| 개인화 삽입 지점 | 장애물 정도 | 적·보스·무기·아이템·컬러 | **서바이버** |
| 웹 구현 난이도 | 낮음 | 낮음 (Canvas 2D) | 동일 |
| 60초 영상 하이라이트 | 밋밋함 | 화면 가득 찬 적 + 보스 | **서바이버** |

오토러너는 "보는 게임"이라 게임 중심 전략과 충돌한다.

## 4. 코어 게임플레이

### 4.1 세션 구조 — 하루 = 3분

게임 내 시계가 **06:00 → 24:00**으로 흐른다. 실시간 180초.
(1초 = 게임 내 6분)

| 게임 내 시각 | 실시간 | 구간명 | 내용 |
|---|---|---|---|
| 06:00–09:00 | 0–30s | 아침 | 튜토리얼 구간. 약한 적 소수. 첫 레벨업 유도 |
| 09:00–12:00 | 30–60s | 오전 | 웨이브 1. 적 종류 2개 |
| 12:00–13:00 | 60–70s | **점심** | **적 없음.** 회복 아이템 집중 배치. 숨 고르기 |
| 13:00–18:00 | 70–140s | 오후 | 웨이브 2. 최다 스폰. 미니보스 1회 |
| 18:00–21:00 | 140–160s | 저녁 | 스폰 급감. 강화 선택 2회 연속 |
| 21:00–24:00 | 160–180s | **밤** | **오늘의 보스전** |

**점심 구간이 설계의 핵심이다.** 긴장을 한 번 풀어줘야 보스전의 대비가 산다.
동시에 "점심시간엔 평화롭다"는 공감 포인트가 된다.

### 4.2 조작

- **이동만.** WASD / 방향키 / 터치 드래그.
- 공격은 전부 자동.
- 레벨업 시에만 카드 3장 중 1장 클릭.

> 심사자가 5초 안에 이해해야 한다. 버튼은 존재하지 않는다.

### 4.3 성장 루프

- 적 처치 → 경험치 오브 드랍 → 수집 → 레벨업
- 세션당 레벨업 **6~7회** (약 25~30초 간격)
- 레벨업 시 카드 3장 제시 → 1장 선택
- 무기 슬롯 4 / 패시브 슬롯 4

**무기 (4종, 고정)**

| 무기 | 동작 | 초기 지급 조건 |
|---|---|---|
| ☕ 커피 | 전방 직선 투사체, 고연사 | mood = energetic |
| 🎧 이어폰 | 주변 공전 오브, 접촉 데미지 | mood = calm |
| 😮‍💨 한숨 | 근접 원형 범위 + 넉백 | mood = exhausted |
| 📱 스마트폰 | 자동 조준 유도탄, 저데미지 | mood = anxious / joyful |

각 무기 Lv1~5. 강화 시 투사체 수 / 범위 / 쿨다운 개선.

**패시브 (4종, 고정)**

| 패시브 | 효과 |
|---|---|
| 카페인 | 이동속도 +10%/Lv |
| 끈기 | 최대 체력 +15%/Lv |
| 요령 | 쿨다운 -8%/Lv |
| 눈치 | 획득 범위 +20%/Lv |

### 4.4 적 아키타입 (5종, 고정)

**AI는 이 5개의 이름과 색만 바꾼다. 행동과 수치는 절대 불변.**

| 아키타입 | 행동 | HP | 속도 | 기본 이름 |
|---|---|---|---|---|
| `swarm` | 느리게 직선 추적, 다수 | 10 | 0.6 | 쌓인 알림 |
| `rusher` | 빠르게 돌진, 소수 | 15 | 1.6 | 지각 |
| `ranged` | 거리 유지 + 투사체 | 12 | 0.7 | 이메일 |
| `tank` | 매우 느림, 고체력 | 60 | 0.35 | 회의 |
| `splitter` | 사망 시 swarm 2마리 분열 | 25 | 0.8 | 잔소리 |

### 4.5 보스 (1종, 고정 패턴)

- HP 800 / 제한시간 20초 (미처치 시 자동 종료, 등급만 하락)
- 패턴 3개 순환: **돌진 → 원형 탄막 → 소환(swarm 6)**
- **이름·외형·도발 대사만 AI가 채운다.**

```
        ⚔  BOSS  ⚔
   「 피드백 4차 」
   "이거 다시 해줄 수 있어요?"
   HP ▓▓▓▓▓▓▓▓░░░░
```

> 이 화면 하나가 이 게임의 모든 화제성을 담당한다.

### 4.6 종료 조건

- 체력 0 → **게임오버 아님.** "오늘은 여기까지" 처리 후 즉시 엔딩 카드
- 180초 생존 + 보스 처치 → 클리어
- **어떤 경우에도 실패 문구를 쓰지 않는다.** 내 하루에 FAILED를 띄우지 않는다.

### 4.7 엔딩 카드

```
  ─────── 2026.07.29 ───────
        RANK   S

   "커피 세 잔으로 마감을 이긴 하루."

   처치        312
   최고 레벨    7
   생존        3:00
   쓰러뜨린 보스  피드백 4차
  ──────────────────────────
        [ 이미지 저장 ]  [ 다시 ]
```

**등급 산식**
```
score = 처치수 × 1 + 레벨 × 30 + 생존초 × 2 + (보스처치 ? 300 : 0)
S ≥ 900 / A ≥ 700 / B ≥ 500 / C < 500
```

공유 버튼은 **이 화면에만** 존재한다.

## 5. 개인화 레이어 (일기)

### 5.1 입력 UX

빈 텍스트박스 금지. 캐릭터가 3개를 묻는다. 각 40자 제한.

```
  🐈 "오늘 뭐가 제일 힘들었어?"      → [                    ]
  🐈 "그래도 좋았던 거 하나만."       → [                    ]
  🐈 "오늘 너를 버티게 한 건?"        → [                    ]

         [ 던전 생성 ]        [ 그냥 하기 → ]
```

- **"그냥 하기"는 항상 노출된다.** 프리셋 3종 중 랜덤으로 즉시 시작.
- 3개 중 1개만 채워도 생성 가능.

### 5.2 일기 → 게임 매핑

| 일기 질문 | 게임 요소 |
|---|---|
| 힘들었던 것 | **보스 이름 + 도발 대사** / 적 이름 일부 |
| 좋았던 것 | **점심 회복 아이템** 이름 + 엔딩 문구 톤 |
| 버티게 한 것 | **시작 무기 결정** + 패시브 1개 선지급 |
| (전체 톤 분석) | 배경 팔레트 · BGM 템포 · 엔딩 한 줄 평 |

### 5.3 생성 결과 스키마 (LLM 출력 계약)

**수치는 단 하나도 포함되지 않는다.**

```json
{
  "title": "마감 전야",
  "mood": "exhausted",
  "palette": "midnight",
  "enemies": [
    { "archetype": "swarm",    "name": "쌓인 알림",   "emoji": "🔔" },
    { "archetype": "rusher",   "name": "지하철 2호선", "emoji": "🚇" },
    { "archetype": "ranged",   "name": "확인 부탁드립니다", "emoji": "📧" },
    { "archetype": "tank",     "name": "주간 회의",    "emoji": "🗓" },
    { "archetype": "splitter", "name": "추가 요청",    "emoji": "📎" }
  ],
  "boss": {
    "name": "피드백 4차",
    "emoji": "📝",
    "taunt": "이거 다시 해줄 수 있어요?"
  },
  "lunch_item": { "name": "김치찌개", "emoji": "🍲" },
  "starting_weapon": "sigh",
  "ending_line": "커피 세 잔으로 마감을 이긴 하루."
}
```

**제약**
- `archetype` — 5개 enum 고정, 5개 전부 필수, 순서 고정
- `mood` — `energetic | calm | exhausted | anxious | joyful`
- `palette` — `dawn | noon | sunset | midnight | neon`
- `starting_weapon` — `coffee | earphone | sigh | phone`
- `name` — 최대 12자 / `taunt` — 최대 25자 / `ending_line` — 최대 30자
- 스키마 검증 실패 시 **즉시 폴백** (재시도 1회까지만)

### 5.4 변환 연출 (3~5초)

일기 글자가 그 자리에서 분해되어 픽셀 오브젝트로 재조립되는 애니메이션.

- LLM 응답을 기다리는 시간을 그대로 연출로 덮는다
- **60초 영상의 하이라이트 구간**
- 응답이 먼저 와도 최소 2.5초는 재생 (연출 완성도 우선)

### 5.5 히든 이벤트 (하드코딩)

| 트리거 키워드 | 효과 |
|---|---|
| 야근 / 밤샘 | 팔레트 강제 `midnight`, BGM 템포 -15% |
| 치킨 / 퇴근 / 월급 | 점심 회복량 2배 + 팡파레 |
| 월요일 | 시작 체력 -20%, 엔딩 보너스 +100 |
| 감기 / 아프 / 병원 | 이동속도 -10%, 적 스폰 -20% |

> 구현은 `if`문 4개. 발견 시 공유 유발 효과는 그 몇 배다.

## 6. 기술 설계

### 6.1 아키텍처

```
┌──────────────────────────────┐
│  GitHub Pages (정적)          │
│  · Canvas 2D 게임 엔진        │
│  · 고정 밸런스 테이블          │
│  · 규칙 기반 폴백 생성기       │
└────────────┬─────────────────┘
             │ fetch (POST /generate)
             ▼
┌──────────────────────────────┐
│  Cloudflare Workers (프록시)   │
│  · API 키 은닉 (env)          │
│  · Origin 화이트리스트         │
│  · IP당 분당 5회 rate limit    │
│  · 스키마 검증 후 반환         │
└────────────┬─────────────────┘
             ▼
        Claude API
```

### 6.2 기술 스택

| 영역 | 선택 | 근거 |
|---|---|---|
| 렌더링 | **Canvas 2D (바닐라)** | 엔진 없이 충분. 번들 최소화 |
| 빌드 | Vite | GitHub Pages 배포 단순 |
| 언어 | TypeScript | 스키마 타입 안전성 |
| 프록시 | Cloudflare Workers | 무료 티어 · 키 은닉 |
| 저장 | localStorage | 계정 불필요 |
| 사운드 | 웹 오디오 + CC0 에셋 | 라이선스 명시 |

### 6.3 폴백 설계 (필수)

```
LLM 호출
  ├─ 성공 + 스키마 통과 → 사용
  ├─ 스키마 실패        → 1회 재시도
  ├─ 재시도 실패 / 타임아웃(4s) / 네트워크 오류
  │                     → 규칙 기반 생성기
  └─ 규칙 기반도 불가    → 프리셋 3종 중 랜덤
```

**규칙 기반 생성기**: 키워드 사전(약 120개) 매칭 → 아키타입 이름 치환.
"회의"·"보고"·"발표" → tank / "알림"·"카톡"·"메일" → swarm 방식.

> 심사 중 API가 죽어도 게임은 100% 정상 동작한다.
> 이 이중화는 AI 기술 문서의 핵심 서술 항목이기도 하다.

### 6.4 성능 목표

| 항목 | 목표 |
|---|---|
| 첫 화면 로드 | < 2s (3G 기준) |
| 던전 생성 응답 | < 3s (초과 시 폴백) |
| 프레임 | 60fps @ 적 200마리 |
| 번들 크기 | < 500KB gzip |

객체 풀링으로 적/투사체/오브 재사용. GC 스파이크 방지.

## 8. 개발 우선순위 (MoSCoW)

### Must — 이게 없으면 제출 불가
- [ ] Canvas 게임 루프 + 이동 + 자동 공격
- [ ] 적 5종 아키타입 + 스폰 스케줄러
- [ ] 레벨업 카드 시스템 (무기 4 + 패시브 4)
- [ ] 보스 1종 (패턴 3개)
- [ ] 엔딩 카드 + 등급 산식
- [ ] 일기 입력 → LLM → 스키마 검증 → 적용
- [ ] **규칙 기반 폴백**
- [ ] **"그냥 하기" 경로**
- [ ] Cloudflare Workers 프록시
- [ ] GitHub Pages 배포

### Should — 심사 인상을 좌우
- [ ] 변환 연출 애니메이션
- [ ] 엔딩 카드 이미지 저장
- [ ] 기록 캘린더
- [ ] 히든 이벤트 4종
- [ ] 사운드

### Could — 시간 남으면
- [ ] 팔레트 5종 전부
- [ ] 미니보스
- [ ] 무기 진화

### Won't — 이번엔 안 한다
- 로그인 / 서버 저장 / 결제 / 멀티플레이 / 3D / 음성 입력

## 9. 수용 기준 (Definition of Done)

| # | 기준 |
|---|---|
| 1 | 링크 클릭 후 **10초 내** 플레이 시작 가능 |
| 2 | 일기 미입력으로도 완전한 1판이 돌아간다 |
| 3 | 네트워크를 끊어도 게임이 정상 동작한다 |
| 4 | 3분 세션이 프레임 드랍 없이 완주된다 |
| 5 | 보스 이름에 일기 내용이 반영된다 |
| 6 | 엔딩 카드가 이미지로 저장된다 |
| 7 | 모바일 브라우저(터치)에서 조작된다 |
| 8 | 콘솔에 에러가 하나도 없다 |
| 9 | API 키가 클라이언트 번들에 없다 |
| 10 | 커밋이 기능 단위로 20개 이상 쌓여 있다 |

## 10. 리스크 및 대응

```
당신은 아케이드 게임의 콘텐츠 디자이너입니다.
사용자의 하루 일기를 읽고, 게임에 사용할 이름과 분위기만 정합니다.

절대 규칙:
- 게임의 수치(체력, 공격력, 속도)는 절대 언급하지 마십시오.
- archetype은 주어진 5개를 그대로, 순서대로 사용하십시오.
- 모든 이름은 사용자의 일기에서 실제로 언급된 대상에서 뽑으십시오.
  일기에 없는 것을 지어내지 마십시오.
- 보스는 사용자가 "가장 힘들었다"고 답한 것에서 정하십시오.
- 특정 개인의 실명이 들어오면 역할명으로 바꾸십시오. (예: 김철수 → 팀장님)

- 톤은 진지하되 과장하십시오. 평범한 일도 서사적으로 승격시키십시오.
  ("메일 확인" → "끝없는 회신의 탑")

출력은 제공된 JSON 스키마를 정확히 따르십시오. 그 외 텍스트는 출력하지 마십시오.
```
