# PRD — 마켓 디펜스 (MARKET DEFENSE)

> **주식을 사면 타워가 생긴다. 주가가 오르면 타워가 강해진다.**
>
> NAN 2026 · NHN Game × AI Hackathon 사전 과제
> 문서 버전 v2.0 (단순화) / 2026-07-30

---

## 1. 이 게임을 한 문장으로

**적의 약점에 해당하는 회사 주식을 사서 막는 타워디펜스.**

플레이어가 배워야 할 규칙은 이것뿐이다.

```
   🏃 러너가 온다  →  ❄️ CRYO 주식을 산다  →  냉각탑이 생긴다  →  막는다
```

---

## 2. 설계 원칙

> **1. 규칙은 3개를 넘지 않는다.**
> 매수 = 건설 / 주가 = 타워 성능 / 적의 약점 = 사야 할 종목.
> 이 셋으로 설명이 끝나야 한다.
>
> **2. 계산을 시키지 않는다.**
> 지분율·수익률·담보비율을 플레이어가 암산하게 만들지 않는다.
> 화면에는 "▲11%"와 "Lv2"만 보인다.
>
> **3. 복잡한 건 뒤에 숨긴다.**
> 실제 코인 연동, 레버리지, 폴백은 전부 내부 구현이다.
> 플레이어는 "주가가 움직인다"만 인지하면 된다.

### 제거한 것 (v1 대비)

공매도 · 신용거래 · 마진콜 · IPO · 배당 · 상장폐지 · 지분율 계산 · 시가총액 · 지수 종목 · 8개 연결 축

> 위 항목은 전부 "설명이 필요한" 요소였다. 설명이 필요하면 뺀다.

## 3. 코어 루프 (30초)

```
   ┌─────────────────────────────────────────┐
   │ ① 다음 적 아이콘 확인      🏃            │
   │ ② 약점 종목 매수          [❄️ CRYO 매수] │
   │ ③ 타워 자동 생성 → 슬롯 클릭해 배치       │
   │ ④ 방어                                   │
   │ ⑤ 방어 성공 → 주가 상승 → 타워 자동 강화  │
   └─────────────────────────────────────────┘
                    × 5라운드
```

**한 라운드 = 35초** (준비 10초 + 웨이브 25초)
**총 세션 = 약 3분**

---

## 4. 규칙 3개

### 규칙 1. 매수 = 건설

주식을 사면 **그 자리에서 타워가 나온다.** 따로 건설 버튼이 없다.

| 보유 주식 | 타워 |
|---|---|
| 10주 | Lv1 |
| 30주 | Lv2 |
| 60주 | Lv3 |

매도하면 타워가 사라지고 현금이 들어온다.

### 규칙 2. 주가 = 타워 성능

```
   🔥 PYRO  1,240원  ▲ +11%
   → 화염포탑 공격력 +11%
```

**주가 변동률이 그대로 공격력 변동률이다.** 계산 없음.

- 주가 오름 → 타워가 강해짐 (타워에 초록 빛)
- 주가 내림 → 약해짐 (빨간 빛)

### 규칙 3. 적의 약점 = 사야 할 종목

| 적 | 약점 | 사야 할 것 |
|---|---|---|
| 🏃 러너 (빠르고 많음) | 감속 | ❄️ **CRYO** |
| 🛡 탱커 (느리고 단단) | 지속딜 | 🔥 **PYRO** |
| 🔰 실드 (보호막) | 관통 | ⚡ **VOLT** |

**다음 라운드에 올 적은 항상 화면 상단에 아이콘으로 표시된다.**
그리고 **그 종목은 미리 오르기 시작한다.** 빨리 사면 싸게 산다.

## 5. 구성 요소

### 종목 = 타워 (3개)

| 티커 | 타워 | 공격 | 가격 성격 |
|---|---|---|---|
| 🔥 **PYRO** | 화염포탑 | 광역 지속딜 | 변동 큼 |
| ❄️ **CRYO** | 냉각탑 | 감속 + 약한 딜 | 변동 작음 |
| ⚡ **VOLT** | 전기탑 | 단일 강타 · 관통 | 변동 보통 |

### 적 (3종 + 보스)

| 적 | HP | 속도 | 특징 |
|---|---|---|---|
| 🏃 러너 | 40 | 빠름 | 다수 |
| 🛡 탱커 | 320 | 느림 | 맷집 |
| 🔰 실드 | 140 | 보통 | 약점 외 공격 60% 감소 |
| 👑 보스 | 2,400 | 느림 | 3종 타워 모두 필요 |

### 라운드 (5 + 보스)

| R | 적 | 학습 목표 |
|---|---|---|
| 1 | 러너 | **튜토리얼** — 매수하면 타워가 생긴다 |
| 2 | 탱커 | 적마다 사야 할 종목이 다르다 |
| 3 | 실드 | 예고를 보고 미리 사면 싸다 |
| 4 | 러너 + 탱커 | 두 종목을 동시에 관리 |
| 5 | 3종 복합 | 자금 배분 |
| 👑 | 보스 | 총력전 |

### 하단 힌트 줄

항상 **한 문장**으로 지금 뭘 해야 하는지 알려준다.

```
R1  "러너는 냉각(❄️)에 약합니다. CRYO를 사보세요."
R2  "탱커가 옵니다. PYRO가 오르기 전에 사세요."
R3  "예고를 보고 미리 사면 더 쌉니다."
R4  "두 종류가 옵니다. 자금을 나누세요."
R5  "지금 팔면 타워가 사라집니다. 신중히."
```

**이 한 줄이 튜토리얼 전부다.** 별도 튜토리얼 화면 없음.

## 8. 주가는 어떻게 움직이나 (내부 구현)

> 플레이어에게는 설명하지 않는다. 문서·심사용 서술이다.

### 8.1 공식

```
Δ = realΔ × 40 × β   +   waveEffect   +   noise
     ─────────────       ───────────       ─────
     실제 코인 시세        예고 선반영        정체 방지
```

| 항 | 역할 |
|---|---|
| `realΔ × 40 × β` | 실제 코인 변동률에 레버리지. 시장의 파도 |
| `waveEffect` | 예고된 적의 약점 종목이 오른다 (라운드당 최대 +12%) |
| `noise` | 실제 시세가 멈춰도 밋밋하지 않게 (±0.4%) |

**곱하지 않고 더한다.** 실제 시세가 0이어도 게임은 움직인다.

### 8.2 종목별 실제 코인 매핑

BTC 하나만 쓰면 3종목이 같이 움직여 **선택이 사라진다.** 따로 매핑한다.

| 종목 | 소스 | β |
|---|---|---|
| PYRO | KRW-BTC | 1.5 |
| CRYO | KRW-ETH | 0.6 |
| VOLT | KRW-XRP | 1.0 |

### 8.3 왜 코인 API인가

**심사가 언제 열릴지 모르기 때문이다.** 주식 API는 주말·새벽에 정지한다.
심사자가 토요일 새벽에 링크를 열었을 때 차트가 멈춰 있으면 그걸로 끝이다.

Upbit을 쓰는 이유: **시세 조회에 API 키가 불필요**해서 프록시 서버 없이 GitHub Pages에서 직접 호출된다. CORS 허용, WebSocket 공개.

### 8.4 폴백

```
   WebSocket 실패 / 타임아웃 2s
        ↓
   내부 난수 생성(GBM)으로 대체 · UI에 조용히 배지 표시
        ↓
   게임은 100% 동일하게 작동
```

### 8.5 상단 티커 (선택)

```
● LIVE   BTC ▼2.1%  ETH ▲0.4%  XRP ▼1.2%
```

밸런스 영향 0. **"진짜 데이터구나"를 3초에 전달하는 유일한 UI.**

## 11. 개발 우선순위

### Must
- [ ] TD 코어: 경로 · 스폰 · 슬롯 배치 · 자동 공격 · 기지 HP
- [ ] 타워 3종 + 적 3종 + 보스
- [ ] **매수 → 타워 생성** (규칙 1)
- [ ] **주가 변동률 → 공격력** (규칙 2)
- [ ] **예고 → 약점 종목 상승** (규칙 3)
- [ ] 하단 힌트 줄 (튜토리얼 대체)
- [ ] 6라운드 진행
- [ ] Upbit 연동 + 폴백
- [ ] 엔딩 카드
- [ ] GitHub Pages 배포

### Should
- [ ] 상단 실시간 티커
- [ ] AI 뉴스 헤드라인 (예고를 뉴스로 위장)
- [ ] 엔딩 이미지 저장
- [ ] 사운드

### Won't
공매도 · 신용거래 · IPO · 배당 · 상장폐지 · 로그인 · 실제 현금 · 멀티플레이 · 맵 다수

## 14. 60초 영상 콘티

| 구간 | 화면 |
|---|---|
| 0–5s | 타이틀 + 상단 실시간 티커 (진짜 데이터임을 보여줌) |
| 5–12s | **"🏃 러너" 예고 → CRYO 매수 → 냉각탑 생성** ⭐ |
| 12–22s | R1 방어. 냉각탑이 러너를 늦춘다 |
| 22–32s | **CRYO 주가 ▲ → 타워가 초록빛으로 강화** ⭐ |
| 32–45s | R3~4. 두 종목 동시 관리, 화면이 바빠짐 |
| 45–55s | 보스전 |
| 55–60s | 엔딩 카드 (RANK + 후회 한 줄) |

> **5–12초와 22–32초가 이 영상의 전부다.**
> "샀더니 타워가 생긴다"와 "주가가 오르니 강해진다".
> 이 둘만 보이면 심사자는 게임을 이해한 것이다.
