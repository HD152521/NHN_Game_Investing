## 00 · COLOR SYSTEM — 색이 곧 게임 정보

한국식 상승=적 / 하락=청. **차트색과 진영색이 같은 시스템**이므로, 파란 캔들이 길어지는 것 자체가 "적이 강해진다"는 신호다.

| 토큰 | HEX | 용도 |
|---|---|---|
| `BG-0` | `#070A12` | 최심층 하늘 |
| `BG-1` | `#0F1524` | 중경 건물 · 패널 |
| `BG-2` | `#1A2236` | 근경 · 발판 |
| `LINE` | `#05070C` | 외곽선 전용 |
| `TEXT` | `#E8ECF4` | 본문 |
| `MUTED` | `#7C89A3` | 보조 · 비활성 |

- **▲ 상승 = 아군** — `#FF4D5A` / 음영 `#B32330`. 아군 유닛·타워·내 기지·양봉 캔들. 실루엣은 **둥글게**
- **▼ 하락 = 악당** — `#2E86FF` / 음영 `#1A4E9E`. 베어 세력 전원·음봉 캔들. 실루엣은 **각지게**
- **재화(진영색과 겹치지 않음)** — `GOLD #FFC53D`(예측 보상) / `AUM #9B6BFF`(운용자금). **캐릭터·배경에 쓰지 않는다**

### 이중 인코딩
아군 = 원형(둥근 어깨·곡선) / 악당 = 각형(스파이크·꺾인 실루엣).
색약 모드에서도 **형태 · ▲▼ 기호 · 캔들 채움**만으로 판별 가능해야 한다.

## 02 · GROUND — 발판 (유닛이 실제로 서는 면)

전투가 일어나는 **유일한 평면**. 상단 모서리 **1px 림 라이트**로 지면선을 명확히.
이 선 위에 모든 발이 픽셀 단위로 정렬된다.

`3840×360 strip` · `magenta above surface` · `seamless L↔R`

| ID | 지역 | 내용 |
|---|---|---|
| `GND-R1` | 여의도 | 연마 화강암 이음선, 낮은 화단 경계석, 맨홀 뚜껑 |
| `GND-R2` | 판교 | 도색 라인 마킹, 잔디 띠, 매립 조명 스트립 |
| `GND-R3` | 울산 | 매립 레일, 위험 사선 도색, 배수 그레이팅 |

### 발판 상태 변형 — 같은 타일, 3단계 (`GND-STATE`, 한 장에)
- **정상** — 웨이브 시작 상태
- **균열** — 적이 절반 이상 전진했을 때 덧깔기
- **함몰** — 후반 웨이브. 균열에 **청색 잔광만** 스며듦

### 타워 설치 슬롯 (발판 위 3상태 데칼, 512×512 한 장에)
비활성(점선 사각) · 배치 가능(적색 실선 + 코너 브래킷) · 배치 불가(회색 사선 해칭).
발판과 같은 원근, 글자 없음.

## 04 · ALLY UNITS — 아군 3종 "장 마감 후에도 남은 사람들"

3헤드 비율, 정장을 전투용으로 개조. 얼굴은 단순하게, **아니메 과장 금지**.
반드시 **한 장에 3종 나란히** 생성.

`3072×1024` · `feet on one baseline` · `facing right`

| ID | 이름 | 비용 | 정체 |
|---|---|---|---|
| `A-01` 근거리 | **개장벨 사환** | 30G | 놋쇠 **개장벨을 뒤집어 쓴** 최말단 사환. 팔에 감은 시세 전표, 벨 채를 곤봉처럼. 값싸고 많고, 제일 먼저 죽는다. `rounded silhouette` `smallest of three` `bell-clapper club` |
| `A-02` 원거리 | **호가 통신원** | 60G | 등에 **티커테이프 릴**을 짊어진 신호수. 어깨 위 접이식 집게 안테나, 한 손에 신호탄 권총. 풀린 테이프가 몸을 한 바퀴 감아 원거리임을 알린다. `tape reel backpack` `flare pistol` `mid build` |
| `A-03` 탱커 | **락업 반장** | 90G | 가장 크고 둥글다. 뜯어온 **금고문을 방패로** 들고, 다이얼이 그대로 붙어 있다. 두꺼운 곡선 어깨패드, 발은 넓게. 밀려도 안 팔리는 실루엣. `vault-door shield` `broad stance` `bulkiest` |

### 파트 분리 시트
애니메이션은 AI로 뽑지 않는다. 정적 스프라이트 1장 + 파트 분리(몸통·상완·전완·허벅지·정강이·무기)를 받아 **걷기·공격은 코드에서 파트 회전과 스쿼시&스트레치로** 만든다. `2048×2048`, 아군 3종 각각.

## 10 · GATES — 생성 순서와 통과 조건

> 앞 게이트를 못 넘으면 다음으로 가지 않는다.
> **캐릭터 한 장을 20번 다시 뽑는 게 스타일 어긋난 50장보다 빠르다.**

| # | 대상 | 통과 조건 |
|---|---|---|
| 1 | 아군 3종 (`A-01~03`) | **스타일 판정 기준.** 이 톤으로 캐릭터가 성립하는지가 나머지 전부를 결정한다 |
| 2 | 지상 악당 3종 (`E-01~03`) | 아군과 나란히 놓고 **단색 실루엣으로 채워** 진영이 구분되는지. 안 되면 원/각 규칙을 더 밀어붙인다 |
| 3 | R1 뒷배경 + 발판 | 1·2번 스프라이트를 **실제 사용 크기로 축소해** 발판 위에 세우고 배경에 묻히는지 본다 |
| 4 | 타워 3종 + 기지 2종 | 전투 화면 한 개를 실제로 조립한다 |
| 5 | UI + 스킬 이펙트 | 조립된 화면 위에 얹어 **차트 패널과 톤이 이어지는지** 최종 확인. **이 아트 방향의 존재 이유다** |
| 6 | 나머지 지역 · 날씨 · 타이틀 | 스타일 확정 이후에만 대량 생산 |
