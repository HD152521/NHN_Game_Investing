# PART 1. 아트 방향 결정

## 1.1 픽셀 레트로를 버린 이유 (실무적 이유)

PRD 오픈이슈 O-5는 `픽셀 레트로 vs 플랫 벡터`였습니다. **플랫 벡터로 확정**을 권합니다. 감성 취향이 아니라 실무 제약 때문입니다.

- **AI 이미지 생성은 픽셀 아트를 제대로 못 만듭니다.** 픽셀 그리드가 어긋나고 안티에일리어싱이 지저분하게 섞여서, 확대하면 "픽셀 아트처럼 보이는 흐릿한 그림"이 나옵니다. 게임에 쓰려면 결국 사람이 전부 다시 찍어야 합니다.
- 플랫 벡터는 AI가 가장 잘하는 영역이고, 스타일 일관성 유지도 훨씬 쉽습니다.
- **결정적 이유**: 이 게임은 화면 위쪽 1/4이 실시간 차트 UI입니다. 밝고 아기자기한 픽셀 전투 화면 아래에 금융 차트가 붙으면 두 개가 서로 다른 게임처럼 보입니다. **어두운 금융 터미널 톤으로 통일해야 한 화면으로 읽힙니다.**

## 1.2 확정 스타일: **파이낸셜 느와르 (Financial Noir)**

> 어두운 트레이딩 터미널 위에서 벌어지는 플랫 벡터 전쟁.

| 요소 | 방향 |
|---|---|
| 베이스 | 딥 네이비~차콜의 어두운 배경. 차트 패널과 전투 화면이 같은 톤으로 이어짐 |
| 형태 | 굵고 깔끔한 외곽선, 단순한 실루엣, 그라디언트 최소 |
| 조명 | 캐릭터·건물 윤곽에 얇은 림 라이트(rim light) 한 줄. 이것만으로 어두운 배경에서 실루엣이 살아남 |
| 채도 | 배경은 저채도, 아군·적군·재화만 고채도 → **시선이 자동으로 게임 정보에 감** |
| 톤 | 진지하되 무겁지 않게. 캐릭터는 약간 과장된 비율(2.5~3헤드)로 위트 |
| 뷰 | **엄격한 측면(side profile) 직교 투상** — 일자형 게임의 절대 조건 |

## 1.3 색 시스템 ★ 중요한 결정 하나

**한국 증권 관습은 상승=빨강, 하락=파랑입니다.** 글로벌 코인 거래소는 반대(상승=녹색)입니다. MVP가 국내 주식 + 한국 유저이므로 **한국식을 권합니다.** 그리고 여기서 좋은 게 하나 나옵니다.

> **하락 = 파랑 = 적군(베어 세력)**, **상승 = 빨강 = 아군**
> 차트 색과 진영 색이 **같은 시스템**이 됩니다.
> 차트에 파란 캔들이 길게 뜨면 그게 곧 "파란 적군이 강해진다"는 뜻이라, **색 자체가 게임 정보가 됩니다.**

# PART 2. AI 생성 실전 규칙

**이 파트를 먼저 읽고 뽑으셔야 재작업이 없습니다.**

### R1. 스타일 앵커를 글자 하나 바꾸지 말고 복붙하세요

아래 `[STYLE]` 블록을 **모든** 프롬프트에 그대로 붙입니다. 문장을 조금씩 바꾸면 스타일이 조금씩 흔들려서 나중에 모아놓으면 따로 놉니다.

### R2. 투명 배경은 마젠타로 뽑고 후처리하세요

대부분의 이미지 모델은 진짜 투명 배경을 못 만듭니다. **`flat magenta #FF00FF background`** 로 뽑은 뒤 색 범위 선택으로 제거하세요. 마젠타를 쓰는 이유는 게임 아트에 거의 등장하지 않는 색이라 키잉이 깔끔하게 떨어지기 때문입니다. (흰 배경은 캐릭터의 흰 부분까지 같이 지워집니다.)

### R3. 같은 계열은 한 장에 나란히 뽑으세요

유닛 3종, 타워 3종처럼 **서로 비교될 에셋은 따로 뽑으면 100% 어긋납니다.** `character lineup sheet, 3 characters side by side, identical art style and scale` 로 한 장에 뽑고 나중에 자르는 게 훨씬 잘 됩니다.

### R4. 측면 뷰를 집요하게 반복하세요

AI는 자꾸 3/4 뷰(비스듬히)로 갑니다. `strict side profile, orthographic, facing right, no perspective` 를 넣고, 그래도 틀리면 재생성하세요. **일자형 게임에서 3/4 뷰 스프라이트는 못 씁니다.**

### R5. 애니메이션은 AI로 뽑지 마세요

프레임 간 일관성이 절대 안 나옵니다. **정적 스프라이트 1장만 뽑고**, 걷기·공격은 코드에서 변형(스켈레톤, 스쿼시&스트레치, 파트 회전)으로 처리하세요. 필요하면 파트를 분리해서 뽑으세요 (몸통 / 팔 / 무기 따로).

### R6. 모델별 강점

| 모델 | 잘하는 것 |
|---|---|
| Midjourney | 배경·분위기·세계지도. 디테일과 톤이 가장 좋음 |
| Flux | 깔끔한 벡터풍 오브젝트, 선이 선명함. 타워·아이콘에 강함 |
| GPT Image / DALL·E | 지시 준수율이 높음. "측면 뷰", "3개 나란히" 같은 구조적 요구에 강함 |
| Ideogram | 이미지 안에 글자를 넣어야 할 때 (타이틀 로고) |

# PART 3. 스타일 앵커 블록

## `[STYLE-CORE]` — 모든 프롬프트에 붙임

```
flat vector game art, bold clean black outlines, limited color palette,
dark financial-noir aesthetic, deep navy and charcoal base
(#070A12, #0F1524, #1A2236), thin cyan-white rim light along edges,
minimal flat shading with no gradients, crisp readable silhouette,
2D game asset, modern stylish, slightly stylized proportions,
high contrast between subject and background
```

## `[STYLE-SPRITE]` — 유닛·타워·건물에 추가

```
strict side profile view, orthographic projection, facing right,
no perspective, full body visible, centered composition,
isolated on flat magenta #FF00FF background, no shadow, no ground plane,
sharp edges suitable for cutout
```

## `[STYLE-BG]` — 배경 레이어에 추가

```
wide panoramic horizontal composition, side-scrolling game background layer,
flat orthographic side view, no characters, no foreground objects,
seamlessly tileable horizontally with matching left and right edges,
desaturated background tones so foreground characters stay readable
```

# 부록. 프롬프트가 안 먹을 때

| 증상 | 대응 |
|---|---|
| 3/4 뷰로 나온다 | `strict side profile` 를 프롬프트 **맨 앞**으로 옮기고, `absolutely no perspective, flat orthographic, like a technical elevation drawing` 추가 |
| 3개가 스타일이 다르다 | 한 장에 뽑는 프롬프트로 바꾸고 `identical art style, identical line weight, identical scale` 를 반복 |
| 배경이 투명하지 않다 | 마젠타 지정을 프롬프트 **끝**에 두고 `solid uniform flat magenta background, absolutely no shadow, no gradient in background` 로 강화 |
| 글자가 멋대로 들어간다 | 네거티브에 `text, letters, numbers, typography, signage, watermark` 넣고, 그래도 나오면 후처리로 지움 |
| 너무 밝고 아기자기하다 | `dark, muted, low saturation, night scene, serious tone` 추가 + `pastel, cute, chibi, bright` 를 네거티브에 |
| 캐릭터가 배경에 묻힌다 | 배경 프롬프트에 `very low contrast, heavily desaturated, hazy` 강화. 배경을 어둡게 하는 것보다 **채도를 죽이는 게** 효과적 |
