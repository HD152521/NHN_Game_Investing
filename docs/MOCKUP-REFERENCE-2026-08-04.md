## 5. `result` — DISCLOSURE 공개 연출 ⚠️ 미구현

목업이 규정한 화면 구성:

```

┌─────────────────────────────┐
│ 2026.07.30 · KRX    정기공시 │  ← 금색 머리띠
├─────────────────────────────┤
│ 분기 실적 발표               │
│ 영업이익                     │
│ +31.4%                      │  ← 큰 수치, 상승 녹색
├─────────────────────────────┤
│ 당신의 예측    ▲ 상승 · LONG │
│ 실제 결과      ▲ +3.82%     │
│ 방어한 웨이브   8 / 8        │
└─────────────────────────────┘
        [ S 등급 인장 ]
  + 3,200 골드 · + ₩2.4M 운용자금 · 도감 카드 3장 획득
        "화면을 눌러 계속"
```

배경: 어두운 캔들 실루엣이 화면 전체에 깔린다.

### ⚠️ 이 화면을 그대로 만들면 안 되는 이유

상단 카드의 **"분기 실적 발표 / 영업이익 +31.4%"는 실데이터가 있어야 성립한다.**
지금 차트는 전부 합성(`generateChartSet`)이라 그런 공시가 존재하지 않는다.
숫자를 지어내면 이 게임이 약속한 **"어느 회사의 어떤 날이었는지 공개된다"**(`GATE_HINT`)가
거짓이 된다 — 정체 공개가 이 게임의 유일한 훅인데, 그 훅을 가짜로 채우면 남는 것이 없다.

**만들 수 있는 것과 없는 것**

| 요소 | 지금 가능한가 | 근거 |
|---|---|---|
| 당신의 예측 / 실제 결과 / 방어한 웨이브 | ✅ | `ClosedPosition` · `CombatState`에 전부 있다 |
| 등급 인장 · 보상 3종 | ✅ | `Settlement`이 이미 계산한다 |
| 캔들 실루엣 배경 | ✅ | `ChartSet.bars` |
| 날짜 `2026.07.30` | ⚠️ 합성이라면 가능 | `dateLabelFromSeed`와 같은 규칙 |
| **종목 · 거래소 · 공시 본문 · 영업이익** | ❌ | 실데이터 선행 (§10 파이프라인) |

→ **권장**: 상단 카드를 "그날의 성격"(archetype · 시장 이벤트)으로 채우고, 실데이터가
붙는 날 그 자리를 진짜 공시로 교체하라. 지금 구현된 공개 연출 6단계 중 ①②③이
막혀 있는 것과 정확히 같은 이유다(`reveal.ts` `blockedBy`).

## 7. 적 5종 아트 레퍼런스 ⚠️ 미반영

목업 PNG 5장이 규정한 실루엣:

| 파일 | 성격 | 대응 추정 | 특징 |
|---|---|---|---|
| `가위맨` | 지상 · 근접 | 러셔 계열 | 정장 + 붉은 대형 가위. 눈만 적색 발광 |
| `원거리유령` | 지상 · 원거리 | 카이터 계열 | 후드 망령 + 붉은 밧줄 결박. 부유(그림자 있음) |
| `파쇄기` | 지상 · 탱커 | 블로커/탱크 계열 | 문서 파쇄기 로봇. 종이 조각 흩날림 |
| `자물쇠` | 지상 · 탱커 | 탱크 계열 | 자물쇠 머리 + 사슬 결박 골렘. 가장 큼 |
| `공중유닛` | 공중 | 사이렌 계열 | 확성기 드론 + 음파 링 3겹 |

### 공통 언어 (5장에서 추출)

- **적색은 눈·무기·구속구에만** — 몸체는 무채색 계열 어둠
- **얼굴이 없다** (아트 시트 §05 "얼굴 없는 하락 압력"과 일치)
- 금융 은유를 물체로 (가위=손절, 파쇄기=공시 은폐, 자물쇠=거래정지, 확성기=소문)

### ⚠️ 왜 이번 회차에 반영하지 않았나

`src/sprites/enemy.ts`는 좌표 기반 드로잉 DSL이다:

```ts
c.poly([[18, 12], [23, 17], [20, 32], [7, 32], [5, 18], [10, 12]], '2');
```

GAME.md가 기록하듯 현재 94개 스프라이트 키는 **디자인 원본과 문자 단위로 일치**한다.
렌더 결과를 눈으로 확인할 수 없는 상태에서 참고 이미지에 맞춰 좌표를 다시 찍으면,
검증된 에셋을 눈 감고 바꾸는 것이 된다.

**작업 조건**: 브라우저에서 스프라이트 시트를 렌더해 놓고(`npm run dev`) 한 종씩
비교하며 고쳐라. 한 번에 5종을 바꾸지 마라 — 어느 변경이 무엇을 깨뜨렸는지 알 수 없게 된다.
